
Copy the `skills/` directory into your project root:

```bash
mkdir -p .claude/skills

# Copy all Ralph skill directories
cp -r /path/to/ralph/skills/ralph .claude/skills/

cp -r /path/to/ralph/skills/ralph-convert-prd .claude/skills/

```
